#LC 217 • Arrays & Hashing

Contains Duplicate

EasyLeetCode
1. Problem Statement

Given an integer array nums, return true if any value appears at least twice, and false if every element is distinct.

2. Input & Output
Input
nums: int[]
1 ≤ n ≤ 105, -109 ≤ nums[i] ≤ 109
Output
boolean — true if duplicate exists
Example 1
nums = [1,2,3,1]
Output: true
// 1 appears at index 0 and 3
Example 2
nums = [1,2,3,4]
Output: false
3. Constraints
  • 1 ≤ nums.length ≤ 105
  • -109 ≤ nums[i] ≤ 109
4. Understanding & Key Observations

Brute force compares every pair — O(n²). Key insight: we only need to know "have I seen this before?" → Hash Set gives O(1) lookup, making one linear pass sufficient.

5. Naive Solution — O(n²) Brute Force

Check every pair (i, j) with i < j. Return true on first match.

class Solution:
    def containsDuplicate(self, nums: list[int]) -> bool:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] == nums[j]:
                    return True
        return False

Expected Output

6. Complexity — Naive
Time: O(n²)Space: O(1)
7. Intuition — Optimization

"Have I seen this before?" → Hash Set. Store each number as we go; check the set before inserting. O(1) average lookup replaces O(n) inner scan.

8. Approach — Algorithm
  1. Initialize empty set seen.
  2. For each num: if num in seen → return True.
  3. Else add num to seen.
  4. End of loop → return False.
9. Optimized Code — Hash Set O(n)

        return false;

10. Complexity — Optimized
Time: O(n)Space: O(n)
11. Methods / Variants
Method 1 — Hash Set · O(n) / O(n) ✓ Recommended

Build a hash set on-the-fly. O(1) lookup with early exit.

Method 2 — Sorting · O(n log n) / O(1)

Sort in-place, check adjacent elements. Better space, worse time.

Method 3 — Python One-liner · O(n) / O(n)

return len(nums) != len(set(nums)) — No early exit though.

12. Pattern / Key Takeaway

Pattern: Frequency Hashing — "Have I seen this before?" → Hash Set. This is the #1 most common array pattern, foundational to Two Sum, Group Anagrams, Longest Consecutive Sequence, and hundreds more problems.

#LC 242 • Arrays & Hashing

Valid Anagram

EasyLeetCode
1. Problem Statement

Given two strings s and t, return true if t is an anagram of s. An anagram uses the exact same characters with identical frequencies.

2. Input & Output
Input
s, t: str (lowercase English letters)
1 ≤ len ≤ 5×104
Output
boolean — true if anagram
Example 1
s="anagram", t="nagaram"
Output: true
Example 2
s="rat", t="car"
Output: false
3. Constraints
  • 1 ≤ s.length, t.length ≤ 5×104
  • s and t consist of lowercase English letters
4. Understanding & Key Observations

Anagrams share identical character frequency distributions. Quick check: if lengths differ, immediately false. Then compare frequency maps — a hashmap/counter approach is O(n).

5. Naive Solution — Sorting

Sort both strings. If anagrams, sorted versions are equal.

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return sorted(s) == sorted(t)
var isAnagram = function(s, t) {
    return s.split('').sort().join('') === t.split('').sort().join('');
};
Expected Output
"anagram","nagaram" → true | "rat","car" → false
6. Complexity — Naive
Time: O(n log n)Space: O(1)
7. Intuition

Count character frequencies with a hashmap. Two strings are anagrams iff their frequency maps are identical. Single O(n) pass instead of O(n log n) sort.

8. Approach — Algorithm
  1. If len(s) != len(t) → return False.
  2. Build frequency map for s.
  3. For each char in t, decrement its count.
  4. If any count goes negative → return False.
  5. Return True.
9. Optimized Code — HashMap O(n)
from collections import Counter
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return Counter(s) == Counter(t)
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;
        int count[26] = {};
        for (char c : s) count[c-'a']++;
        for (char c : t) if (--count[c-'a'] < 0) return false;
        return true;
    }
};
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c-'a']++;
        for (char c : t.toCharArray()) if (--count[c-'a'] < 0) return false;
        return true;
    }
}
var isAnagram = function(s, t) {
    if (s.length !== t.length) return false;
    const map = {};
    for (const c of s) map[c] = (map[c]||0) + 1;
    for (const c of t) { if (!map[c]) return false; map[c]--; }
    return true;
};
Expected Output
"anagram","nagaram" → true | "rat","car" → false
10. Complexity — Optimized
Time: O(n)Space: O(1)*
*O(26)=O(1) for lowercase letters
11. Methods
Method 1 — Counter · O(n) / O(1) ✓

Counter(s) == Counter(t) — cleanest Python one-liner.

Method 2 — Fixed Array[26] · O(n) / O(1)

Integer array of size 26. Faster in practice due to cache locality.

Method 3 — Sorting · O(n log n) / O(1)

Sort both strings and compare. Simple but suboptimal.

12. Pattern / Key Takeaway

Pattern: Character Frequency Map — "Same characters, different order" → compare frequency maps. Applies to anagram detection, permutation checking, group-by-signature problems.

Two Sum

EasyLeetCode
1. Problem Statement

Given an array of integers nums and an integer target, return indices of the two numbers that add up to target. Exactly one solution exists. You may not use the same element twice.

2. Input & Output
Input
nums: int[], target: int
2 ≤ n ≤ 104
Output
int[2] — indices [i, j] where nums[i]+nums[j]=target
Example 1
nums=[2,7,11,15], target=9
Output: [0,1]
// 2+7=9
Example 2
nums=[3,2,4], target=6
Output: [1,2]
3. Constraints
  • 2 ≤ nums.length ≤ 104
  • -109 ≤ nums[i], target ≤ 109
  • Only one valid answer exists
4. Understanding & Key Observations

For each element x, we need target - x. Brute force checks all pairs O(n²). Optimization: store each element in a map as we scan, look up the complement in O(1).

5. Naive Solution — O(n²)

Check all pairs (i, j) with i < j.

class Solution:
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        for i in range(len(nums)):
            for j in range(i + 1, len(nums)):
                if nums[i] + nums[j] == target:
                    return [i, j]

            for (int j = i+1; j < nums.size(); j++)
                if (nums[i]+nums[j]==target) return {i,j};
        return {};
    }
};

6. Complexity — Naive
Time: O(n²)Space: O(1)
7. Intuition

For each element x, we need target - x. Store visited elements in {value: index} map. Check if the complement exists before inserting current element.

8. Approach — Algorithm
  1. Init empty map seen = {value: index}.
  2. For each index i: compute complement = target - nums[i].
  3. If complement in seen → return [seen[complement], i].
  4. Else store seen[nums[i]] = i.
9. Optimized Code — One-pass HashMap

            complement = target - num
            if complement in seen:
                return [seen[complement], i]
            seen[num] = i

10. Complexity — Optimized
Time: O(n)Space: O(n)
11. Methods
Method 1 — One-pass HashMap · O(n) / O(n) ✓

Check complement before inserting. Handles [3,3] edge case correctly.

Method 2 — Two-pass HashMap · O(n) / O(n)

Build full map, then scan for complement. Slightly simpler, same complexity.

Method 3 — Two Pointers (if sorted) · O(n log n) / O(1)

Sort + two pointers. O(1) space but loses original indices.

12. Pattern / Key Takeaway

Pattern: Complement Lookup via HashMap — Store visited elements, check complement on each step. Canonical HashMap-in-arrays pattern. Generalizes to 3Sum (sort + fix + two-ptr) and 4Sum.

Group Anagrams

MediumLeetCode
1. Problem Statement

Given an array of strings strs, group the anagrams together. Return in any order.

2. Input & Output
Example 1
strs = ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]]
3. Constraints
  • 1 ≤ strs.length ≤ 104
  • 0 ≤ strs[i].length ≤ 100, lowercase English only
4. Understanding & Key Observations

Anagrams share the same character frequency signature. Use sorted string as the hashmap key to group all anagrams together.

7. Intuition

"eat" sorted = "aet", "tea" sorted = "aet", "ate" sorted = "aet". Use this canonical form as a dict key to group them in one pass.

8. Approach
  1. Init groups = defaultdict(list).
  2. For each string s, compute key = tuple(sorted(s)).
  3. Append s to groups[key].
  4. Return list(groups.values()).
9. Optimized Code
from collections import defaultdict
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        groups = defaultdict(list)
        for s in strs:
            groups[tuple(sorted(s))].append(s)
        return list(groups.values())
var groupAnagrams = function(strs) {
    const map = new Map();
    for (const s of strs) {
        const key = s.split('').sort().join('');
        if (!map.has(key)) map.set(key, []);
        map.get(key).push(s);
    }
    return [...map.values()];
};
10. Complexity
Time: O(n·k log k)Space: O(n·k)
12. Pattern / Key Takeaway

Pattern: Group by Canonical Form — When grouping equivalent items, normalize to a canonical signature and use it as a hashmap key.

Top K Frequent Elements

MediumLeetCode
1. Problem Statement

Given an integer array nums and an integer k, return the k most frequent elements.

2. Input & Output
Example 1
nums=[1,1,1,2,2,3], k=2
Output: [1,2]
3. Constraints
  • 1 ≤ nums.length ≤ 105
  • k is in range [1, number of unique elements]
  • The answer is guaranteed to be unique
7. Intuition

Bucket Sort: Frequencies range 1 to n. Create n+1 frequency buckets. Put numbers into their bucket. Read from the end (highest freq) until we have k elements. O(n) — beats heap's O(n log k).

9. Optimized Code — Bucket Sort
from collections import Counter
class Solution:
    def topKFrequent(self, nums: list[int], k: int) -> list[int]:
        count = Counter(nums)
        buckets = [[] for _ in range(len(nums) + 1)]
        for num, freq in count.items():
            buckets[freq].append(num)
        res = []
        for i in range(len(buckets)-1, 0, -1):
            for num in buckets[i]:
                res.append(num)
                if len(res) == k: return res
var topKFrequent = function(nums, k) {
    const cnt = new Map();
    for (const n of nums) cnt.set(n,(cnt.get(n)||0)+1);
    const buckets = Array.from({length:nums.length+1},()=>[]);
    for (const [n,f] of cnt) buckets[f].push(n);
    const res = [];
    for (let i = buckets.length-1; i > 0 && res.length < k; i--)
        res.push(...buckets[i]);
    return res.slice(0,k);
};
10. Complexity
Time: O(n)Space: O(n)
12. Pattern / Key Takeaway

Pattern: Bucket Sort for Bounded Frequencies — When frequency values are bounded by n, bucket sort achieves O(n). "Top K" problems: use heap O(n log k) or bucket sort O(n).

Product of Array Except Self

MediumLeetCode
1. Problem Statement

Return array where answer[i] = product of all elements except nums[i]. Must run O(n) without division.

2. Input & Output
Example 1
nums = [1,2,3,4]
Output: [24,12,8,6]
// 24=2*3*4, 12=1*3*4, 8=1*2*4, 6=1*2*3
7. Intuition

answer[i] = product_of_all_left × product_of_all_right. Two passes: left to right (prefix), right to left (suffix). Combine into result in O(n) with O(1) extra space.

9. Optimized Code — Prefix × Suffix
class Solution:
    def productExceptSelf(self, nums: list[int]) -> list[int]:
        n = len(nums)
        res = [1] * n
        prefix = 1
        for i in range(n):
            res[i] = prefix
            prefix *= nums[i]
        suffix = 1
        for i in range(n-1, -1, -1):
            res[i] *= suffix
            suffix *= nums[i]
        return res
var productExceptSelf = function(nums) {
    const n = nums.length, res = new Array(n).fill(1);
    let prefix = 1;
    for (let i = 0; i < n; i++) { res[i]=prefix; prefix*=nums[i]; }
    let suffix = 1;
    for (let i = n-1; i >= 0; i--) { res[i]*=suffix; suffix*=nums[i]; }
    return res;
};
10. Complexity
Time: O(n)Space: O(1)*
12. Pattern / Key Takeaway

Pattern: Prefix/Suffix Accumulation — "Everything to the left × everything to the right." Applies to Trapping Rain Water, Max Product Subarray. Avoids division.

#LC 36 • Arrays & Hashing

Valid Sudoku

MediumLeetCode
1. Problem Statement

Determine if a 9×9 Sudoku board is valid. Each row, column, and 3×3 sub-box must contain digits 1–9 without repetition. Empty cells are '.'.

7. Intuition

Track seen digits per row, column, and box simultaneously in ONE pass. Box index: (r//3)*3 + (c//3). If any digit repeats in any set → invalid.

9. Optimized Code
class Solution:
    def isValidSudoku(self, board: list[list[str]]) -> bool:
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]
        for r in range(9):
            for c in range(9):
                v = board[r][c]
                if v == '.': continue
                box = (r//3)*3 + c//3
                if v in rows[r] or v in cols[c] or v in boxes[box]:
                    return False
                rows[r].add(v); cols[c].add(v); boxes[box].add(v)
        return True
var isValidSudoku = function(board) {
    const rows=[...Array(9)].map(()=>new Set());
    const cols=[...Array(9)].map(()=>new Set());
    const boxes=[...Array(9)].map(()=>new Set());
    for(let r=0;r<9;r++)for(let c=0;c<9;c++){
        const v=board[r][c]; if(v==='.') continue;
        const box=Math.floor(r/3)*3+Math.floor(c/3);
        if(rows[r].has(v)||cols[c].has(v)||boxes[box].has(v)) return false;
        rows[r].add(v);cols[c].add(v);boxes[box].add(v);
    }
    return true;
};
10. Complexity
Time: O(81) = O(1)Space: O(81) = O(1)
12. Pattern / Key Takeaway

Pattern: Multi-Constraint Tracking in One Pass — Maintain separate sets for each constraint dimension. Box formula: (r//3)*3 + c//3.

Encode and Decode Strings

MediumLeetCode
1. Problem Statement

Design encode/decode for a list of strings to a single string. Must handle any characters including #, |, etc.

7. Intuition

Length-prefix encoding: Format each string as "{length}#{content}". During decode, read the length, skip #, read exactly that many chars. No delimiter collisions possible.

9. Optimized Code
class Codec:
    def encode(self, strs: list[str]) -> str:
        return ''.join(f'{len(s)}#{s}' for s in strs)

    def decode(self, s: str) -> list[str]:
        res, i = [], 0
        while i < len(s):
            j = s.index('#', i)
            length = int(s[i:j])
            res.append(s[j+1:j+1+length])
            i = j+1+length
        return res
var encode = s => s.map(w => `${w.length}#${w}`).join('');
var decode = function(s) {
    const res=[]; let i=0;
    while(i<s.length){
        const j=s.indexOf('#',i), len=parseInt(s.slice(i,j));
        res.push(s.slice(j+1,j+1+len)); i=j+1+len;
    }
    return res;
};
10. Complexity
Encode O(n)Decode O(n)Space O(n)
12. Pattern / Key Takeaway

Pattern: Length-Prefix Encoding — Encode variable-length data with a length prefix to avoid delimiter ambiguity. Used in HTTP/2 framing, protobuf, network protocols.

#LC 128 • Arrays & Hashing

Longest Consecutive Sequence

MediumLeetCode
1. Problem Statement

Given an unsorted integer array nums, return the length of the longest consecutive sequence. Must run in O(n) time.

2. Input & Output
Example 1
nums = [100,4,200,1,3,2]
Output: 4
// Sequence: 1,2,3,4
Example 2
nums = [0,3,7,2,5,8,4,6,0,1]
Output: 9
3. Constraints
  • 0 ≤ nums.length ≤ 105
  • -109 ≤ nums[i] ≤ 109
4. Understanding & Key Observations

A number is a sequence start only if n-1 is NOT in the set. Only count from starts to avoid O(n²). Total while-loop iterations across all starts = n (amortized O(n)).

7. Intuition

Convert to set for O(1) lookup. For each number, only start counting if it has no predecessor (n-1 not in set). Then count upward. Each element processed at most twice total.

8. Approach
  1. Put all numbers in a hash set.
  2. For each n: if n-1 not in set (sequence start):
  3.     Count up: while n+len in set, increment length.
  4.     Update best = max(best, length).
  5. Return best.
9. Optimized Code — Hash Set O(n)
class Solution:
    def longestConsecutive(self, nums: list[int]) -> int:
        num_set = set(nums)
        best = 0
        for n in num_set:
            if n - 1 not in num_set:
                cur, length = n, 1
                while cur + 1 in num_set:
                    cur += 1; length += 1
                best = max(best, length)
        return best
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> s(nums.begin(),nums.end());
        int best = 0;
        for (int n : s)
            if (!s.count(n-1)) {
                int cur=n, len=1;
                while (s.count(cur+1)) { cur++; len++; }
                best = max(best, len);
            }
        return best;
    }
};
class Solution {
