Reading & Writing Files

Most data science starts with a file. Python's built-in open() reads and writes text files — and a few string methods already give you basic text statistics.

File object — what open(path, mode) returns: a handle with read, readline, readlines, write and seek. Always close it — or better, use with, which closes it for you.

Modes
ModeMeaningIf the file existsIf it doesn't
'r'Read (default)Reads from the startFileNotFoundError
'w'WriteErases it firstCreates it
'a'AppendWrites at the endCreates it
'r+'Read and writeStarts at the beginningFileNotFoundError
'x'Create onlyFileExistsErrorCreates it
Writing: write vs writelines
Python
lines = ["This is Delhi \n", "This is Paris \n", "This is London \n"]
with open("myfile.txt", "w", encoding="utf-8") as f:
    f.write("Hello \n")          # one string
    f.writelines(lines)          # an iterable of strings (no newlines are added for you)

with open("myfile.txt", encoding="utf-8") as f:
    print(f.read())
Output
Hello
This is Delhi
This is Paris
This is London
Reading: read, readline, readlines, seek
Python
with open("myfile.txt", encoding="utf-8") as f:
    print(repr(f.read(9)))       # 'Hello \nTh'   ← 9 characters, across lines
    f.seek(0)                    # jump back to the start
    print(repr(f.readline()))    # 'Hello \n'     ← up to and including the newline
    f.seek(0)
    print(f.readlines())         # ['Hello \n', 'This is Delhi \n', 'This is Paris \n', 'This is London \n']
MethodReturns
f.read() / f.read(n)The whole file / the next n characters, as one string
f.readline()The next line, including its \n
f.readlines()A list of all remaining lines
for line in f:Lines one at a time — memory-friendly for big files
f.seek(n)Moves the position to byte n (0 = start)
Append vs write
Python
with open("notes.txt", "w") as f:
    f.write("Today \n")
with open("notes.txt", "a") as f:        # append keeps what was there
    f.write("Tomorrow \n")
with open("notes.txt") as f:
    print(f.readlines())                  # ['Today \n', 'Tomorrow \n']

with open("notes.txt", "w") as f:        # write erases it first
    f.write("Only this \n")
with open("notes.txt") as f:
    print(f.readlines())                  # ['Only this \n']
Watch out

Opening with 'w' silently wipes the file. Use 'a' to add to it, or 'x' to refuse overwriting.

Quick text statistics
Python
text = """Data science turns raw data into insight. It mixes statistics and programming.

Python is the most popular language for it."""

paragraphs = [p for p in text.split("\n\n") if p.strip()]
sentences = [s for s in text.replace("\n", " ").split(".") if s.strip()]

Key point

split(" ") counts empty strings between double spaces and keeps newlines inside words — split() with no argument is almost always what you want for words.

Python
raw = "Hello!! World@ #2026 [7] [12]"

Files & Folders with os

The os module talks to the operating system: where you are, what's in a folder, and creating, renaming or removing directories — the plumbing behind organising datasets.

Where am I?
Python
import os
start = os.getcwd()              # current working directory
os.mkdir("project")              # create one folder
os.chdir("project")              # move into it
print(os.path.basename(os.getcwd()))   # project

print(os.getcwd() == start)      # True

Nested folders
Python
import os
os.makedirs("data/raw/2026", exist_ok=True)     # creates data, data/raw and data/raw/2026
os.rmdir("data/raw/2026")                       # only works because it's empty

Watch out

os.rmdir refuses non-empty folders. To delete a whole tree use shutil.rmtree(path) — carefully: there's no recycle bin.

Creating folders in bulk
Python
import os
master = "KT"
n, m = 5, 5
for i in range(1, n + 1):
    for j in range(1, m + 1):
        os.makedirs(os.path.join(master, f"{master} {i}", f"{master} {i}.{j}"), exist_ok=True)

total = sum(len(dirs) for _, dirs, _ in os.walk(master)) + 1   # + the master folder itself
print(total)                                                    # 31
Key point

That's the notebook's n*m + n + 1 = 5×5 + 5 + 1 folders. os.walk(top) yields (folder, subfolders, files) for every folder under top.

Reading many text files
Python
import os
os.makedirs("Files", exist_ok=True)
for name, text in [("a.txt", "first"), ("b.txt", "second"), (".DS_Store", "junk")]:
    with open(os.path.join("Files", name), "w") as f:
        f.write(text)

contents = []
for name in sorted(os.listdir("Files")):
    if name.startswith("."):                    # skip hidden files like .DS_Store
        continue
    with open(os.path.join("Files", name)) as f:
        contents.append(f.read())
print(contents)                                 # ['first', 'second']
Tip

Modern alternative: pathlib — [p.read_text() for p in Path("Files").glob("*.txt")] does the same in one line.

NumPy

NumPy Arrays

NumPy's ndarray stores numbers in one contiguous block of memory with a single type — which makes maths on millions of values fast and concise.

ndarray — an N-dimensional array of values that all share one dtype. Operations apply to every element at once (vectorisation), running in C instead of a Python loop.

List vs array
Python
import numpy as np
l = [2, 3, 4, 5]
arr = np.array(l)
print(l, type(l).__name__)            # [2, 3, 4, 5] list
print(arr, type(arr).__name__)        # [2 3 4 5] ndarray
print(l * 2)                          # [2, 3, 4, 5, 2, 3, 4, 5]
print(arr * 2)                        # [ 4  6  8 10]
Key point

list * 2 repeats the list; array * 2 multiplies every element. That difference is the whole point of NumPy.

Array Operations

Arithmetic, aggregation, sorting, joining, splitting and filtering — all without writing a loop.

Element-wise arithmetic
Python
import numpy as np
a = np.array([1, 2, 3, 4])
b = np.array([5, 6, 7, 8])
print(a + 2, a * 2, a / 2)        # [3 4 5 6] [2 4 6 8] [0.5 1.  1.5 2. ]
print(a + b, b - a)               # [ 6  8 10 12] [4 4 4 4]
print(np.add(1, b), np.multiply(a, b))   # [6 7 8 9] [ 5 12 21 32]
Key point

Combining an array with a single number (or arrays of compatible shapes) is called broadcasting — the number is applied to every element.

Aggregations and axes
Python
import numpy as np
m = np.array([[1, 4, 2],
              [3, 4, 6]])
print(m.max(), m.min(), m.sum())      # 6 1 20
print(m.max(axis=0))                  # [3 4 6]   ← down each column
print(m.max(axis=1))                  # [4 6]     ← across each row
print(m.mean(axis=1))                 # [2.33333333 4.33333333]

axis=0

Collapse the rows — one result per column.

axis=1

Collapse the columns — one result per row.

Joining and splitting
Python
import numpy as np
a = np.array([1, 2, 3, 4])
b = np.array([5, 6, 7, 8])
print(np.vstack((a, b)).shape)        # (2, 4)   ← stacked as rows
print(np.hstack((a, b)))              # [1 2 3 4 5 6 7 8]
m = np.array([[1, 2], [3, 4]])
print(np.concatenate((m, m), axis=0).shape)   # (4, 2)
top, bottom = np.vsplit(np.vstack((a, b)), 2)
left, right = np.hsplit(np.vstack((a, b)), 2)
print(top, right[1])                  # [[1 2 3 4]] [7 8]
Slicing and boolean filtering
Python
import numpy as np
arr = np.array([1, 2, 3, 4, 5, 6, 7])
print(arr[1:5], arr[1:5:2], arr[-3:-1], arr[::2])   # [2 3 4 5] [2 4] [5 6] [1 3 5 7]

nums = np.arange(1, 40)
print(nums[nums > 35])                  # [36 37 38 39]
print(nums[(nums % 10 == 0)])           # [10 20 30]
m = np.arange(12).reshape(3, 4)
print(m[1], m[:, 2], m[1:, :2].tolist())   # [4 5 6 7] [ 2  6 10] [[4, 5], [8, 9]]
Correction

The notebook labels slicing “DAP (Distributed Array Protocol)” — that's unrelated. Slicing is plain start:stop:step indexing, per axis, separated by commas.

Watch out

A slice of a NumPy array is a view — changing it changes the original. Use .copy() when you need an independent array. (List slices, by contrast, are copies.)

Do

Replace Python loops over numbers with vectorised expressions: arr[arr > 2], arr * 2, arr.sum().

Avoid

Building NumPy arrays by appending in a loop — collect into a list first, then call np.array(list) once.

Pandas

Series & DataFrames

Pandas gives Python two labelled data structures — the one-dimensional Series and the two-dimensional DataFrame — the everyday tools for tabular data.

Series

One column: values plus an index (labels). Like a NumPy array with names.

DataFrame

A table: several Series sharing one index — rows and named columns, like a spreadsheet or SQL table.

Series
Python
import numpy as np
import pandas as pd

print(s.tolist(), s.index.tolist())      # ['g', 'e', 'e', 'k', 's'] [0, 1, 2, 3, 4]
prices = pd.Series([40, 25, 60], index=["tea", "milk", "coffee"])
print(prices["coffee"], prices.max())    # 60 60
print(prices[prices > 30].to_dict())     # {'tea': 40, 'coffee': 60}

Building a DataFrame from a NumPy array of mixed values (as the notebook does with np.array([['a', 10], …])) turns every value into a string — Age would be text. Use lists or a dict so each column keeps its own type.

Web Scraping

requests & BeautifulSoup

Web scraping = download a page's HTML (requests), then pick out the data you need (BeautifulSoup). It's how you build datasets that don't come as a CSV.

1
Request
requests.get(url, headers=…) downloads the page.
2
Parse
BeautifulSoup(html, "html.parser") turns HTML text into a searchable tree.
3
Extract
find / find_all / select locate elements; .text and .get("href") read them.
4
Store
Collect rows in a list, then save with pandas (to_csv).
1. Download the page
Python
import requests

headers = {"User-Agent": "Mozilla/5.0 (compatible; LearnViaNotesBot/1.0)"}
r = requests.get("https://quotes.toscrape.com/page/1/", headers=headers, timeout=10)
print(r.status_code)          # 200 means OK; 404 not found, 403 forbidden, 429 too many requests
html = r.text                 # decoded text (r.content is the raw bytes)
Key point

Some sites reject requests without a browser-like User-Agent header — that's why the notebook sets one. Always pass a timeout so a slow site can't hang your script.

2. Parse and extract
Python
html = """
<div class="quote">
  <span class="text">“The world as we have created it is a process of our thinking.”</span>
  <small class="author">Albert Einstein</small> <a href="/author/Albert-Einstein">(about)</a>
  <a class="tag" href="/tag/change/">change</a> <a class="tag" href="/tag/thinking/">thinking</a>
</div>
<div class="quote">
  <span class="text">“It is our choices that show what we truly are.”</span>
  <small class="author">J.K. Rowling</small> <a href="/author/J-K-Rowling">(about)</a>
  <a class="tag" href="/tag/choices/">choices</a>
</div>
"""

from bs4 import BeautifulSoup
soup = BeautifulSoup(html, "html.parser")

first = soup.find("div", class_="quote")                      # first match (or None)
print(first.find("small", class_="author").text)              # Albert Einstein

for q in soup.find_all("div", class_="quote"):                # every match
    text = q.find("span", class_="text").text.strip("“”")
    tags = [t.text for t in q.find_all("a", class_="tag")]
    print(text[:22], "|", ", ".join(tags))

import time
from bs4 import BeautifulSoup
from selenium import webdriver
from selenium.webdriver.chrome.options import Options

options = Options()
options.add_argument("--headless=new")        # no visible window
driver = webdriver.Chrome(options=options)    # Selenium Manager finds a matching driver
try:
    driver.get("https://quotes.toscrape.com/scroll")
    last = driver.execute_script("return document.body.scrollHeight")
    while True:                               # scroll until the page stops growing
        driver.execute_script("window.scrollTo(0, document.body.scrollHeight)")
        time.sleep(1.5)
        height = driver.execute_script("return document.body.scrollHeight")
        if height == last:
            break
        last = height
    soup = BeautifulSoup(driver.page_source, "html.parser")
    print(len(soup.find_all("div", class_="quote")))
finally:
    driver.quit()                             # always close the browser

The scikit-learn Workflow

Every scikit-learn model follows the same few steps — so once you know one, you know them all.

1
Load data
Features X (a 2-D table: rows = samples, columns = features) and target y (what to predict).
2
Split
train_test_split holds back unseen data to measure honestly.
3
Create & fit

4
Predict
model.predict(X_test) on data it has never seen.
5
Evaluate

Supervised

Learns from labelled examples: classification (a category — spam / not spam) or regression (a number — price).

Unsupervised

Finds structure in unlabelled data: clustering (K-Means), dimensionality reduction (PCA).

Why split the data?

A model scored on the data it trained on can simply memorise it. Testing on held-out data shows how it will do on new, real inputs. random_state fixes the shuffle so results are reproducible.

Watch out

Overfitting = great on training data, poor on test data (the model memorised noise). Underfitting = poor on both (the model is too simple). Compare train vs test scores to tell them apart.

Polynomial Regression

Linear regression fits a straight line. When the relationship curves, add powers of the input (x², x³…) as extra features — the model stays linear in its coefficients, but the fitted curve bends.

Polynomial features — turning [x] into [1, x, x²] (degree 2). PolynomialFeatures does this; LinearRegression then fits y ≈ b₀ + b₁x + b₂x².

Python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

X = np.array([[1], [2], [3], [4], [5]])
y = np.array([3, 8, 9, 70, 80])

poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)
print(X_poly[1])                                  # [1. 2. 4.]   ← 1, x, x² for x = 2

model = LinearRegression().fit(X_poly, y)
print(model.predict(poly.transform([[6]])).round(1))   # [133.8]
print(round(model.score(X_poly, y), 3))           # 0.884

Text Classification with Naive Bayes

Classify documents by their words: turn each text into word counts, then let Naive Bayes estimate which class makes those words most likely.

1
Vectorise
CountVectorizer builds a vocabulary and turns each document into a vector of word counts (bag of words).
2
Train
MultinomialNB learns how often each word appears in each class.
3
Predict
For a new text it picks the class with the highest probability, assuming words are independent — the “naive” part.
Python
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

texts = ["the team won the cricket match", "stocks fell as markets closed lower",
         "a great goal in the final", "the bank raised interest rates",
         "fans cheered the winning shot", "investors sold shares today"]
labels = ["sports", "finance", "sports", "finance", "sports", "finance"]

vectorizer = CountVectorizer()
X = vectorizer.fit_transform(texts)          # sparse matrix: 6 documents × vocabulary
print(X.shape)                               # (6, 27)

model = MultinomialNB().fit(X, labels)
new = vectorizer.transform(["the match was a great win", "interest rates and shares"])
print(model.predict(new).tolist())           # ['sports', 'finance']
Watch out

Call fit_transform on training text only, then transform on new text — otherwise the vocabulary (and the columns) change between training and prediction.

K-Means Clustering

K-Means groups unlabelled points into K clusters around centres (centroids). The elbow method helps choose K.

1
Start
Pick K initial centroids (k-means++ spreads them out smartly).
2
Assign
Each point joins its nearest centroid.
3
Update
Each centroid moves to the mean of its points.
4
Repeat
Until assignments stop changing (or max_iter).
Python
from collections import Counter
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.60, random_state=0)
km = KMeans(n_clusters=4, init="k-means++", n_init=10, random_state=0).fit(X)
print(km.cluster_centers_.shape)          # (4, 2)
print(sorted(Counter(km.labels_).values()))   # [75, 75, 75, 75]   ← 4 equal clusters
Choosing K: the elbow method

Run K-Means for K = 1…10 and record the WCSS (within-cluster sum of squares, inertia_). It always falls as K grows; the “elbow” where it stops falling sharply is a good K.

Python
from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

wcss = [KMeans(n_clusters=k, n_init=10, random_state=0).fit(X).inertia_ for k in range(1, 11)]
drops = [round(wcss[i] - wcss[i + 1]) for i in range(5)]
print(drops)       # [1621, 644, 335, 23, 18]   ← big drops until K = 4, then small ones

Stop Words

Stop words are very common words (“is”, “the”, “a”) that carry little meaning on their own. Removing them shrinks the text and highlights the words that matter.

Python
from nltk.corpus import stopwords
from nltk.tokenize import word_tokenize

stop_words = set(stopwords.words("english"))
print(len(stop_words), "is" in stop_words, "good" in stop_words)   # 198 True False

txt = "This is not a good time to talk."
kept = [w for w in word_tokenize(txt) if w.lower() not in stop_words and len(w) >= 2]
print(kept)                                  # ['good', 'time', 'talk']
Careful

“not” is a stop word in NLTK's list — so “not a good time” becomes “good time”. For sentiment analysis, removing stop words can flip the meaning; keep negations.

def upper(text):
    return "".join(chr(ord(c) - 32) if "a" <= c <= "z" else c for c in text)

def lower(text):
    return "".join(chr(ord(c) + 32) if "A" <= c <= "Z" else c for c in text)

def title(text):
    return " ".join(upper(w[:1]) + lower(w[1:]) for w in text.split(" "))

print(upper("delhi"), lower("CARTOON"))               # DELHI cartoon
print(title("let us study machine learning today"))   # Let Us Study Machine Learning Today
print(title("hello  world"))                          # Hello  World

Encoding Text as Numbers

Models work with numbers, not words. The simplest encoding gives every word in the vocabulary an ID — then each sentence becomes a list of IDs, and can be turned back.

Build a vocabulary
Python
corpus = ("India, officially the Republic of India, is a country in South Asia. "
          "It is the seventh-largest country by area, the second-most populous country, "
          "and the most populous democracy in the world. "
          "In the Indian Ocean, India is in the vicinity of Sri Lanka and the Maldives.")

from nltk.tokenize import word_tokenize, sent_tokenize
from nltk.corpus import stopwords

stop = set(stopwords.words("english"))
def keep(word):
    return word.lower() not in stop and len(word) >= 2      # drop stop words and punctuation

words = [w.lower() for w in word_tokenize(corpus) if keep(w)]
vocab = sorted(set(words))                                   # sorted → same IDs every run
word_to_num = {w: i for i, w in enumerate(vocab, start=1)}
num_to_word = {i: w for w, i in word_to_num.items()}
print(len(vocab), vocab[:4])                                 # 18 ['area', 'asia', 'country', 'democracy']
Correction

The notebook builds the vocabulary from list(set(words)) — sets have no fixed order, so the IDs change every run. Sort first to make the mapping reproducible.

Interview Prep

Interview Questions

Data science questions that come up in placements and interviews — short answers you can say out loud.

Python & data handling
What's the difference between a Python list and a NumPy array?

A list holds any objects and grows easily, but maths needs a loop. A NumPy array holds one type in contiguous memory, so operations are vectorised — arr * 2 multiplies every element in C, far faster. Arrays also support multi-dimensional shapes, axes and broadcasting.

What does axis=0 vs axis=1 mean?

axis=0 works down the rows — one result per column. axis=1 works across the columns — one result per row. For a (rows, cols) array, sum(axis=0) has one value per column.

Series vs DataFrame?

A Series is one labelled column (values + index). A DataFrame is a table of Series sharing the same index — rows and named columns.

loc vs iloc?

loc selects by labels (index values and column names; slices include the end). iloc selects by integer position (slices exclude the end).

How do you handle missing values?

First measure them (df.isna().sum()). Then per column: drop rows (dropna), fill with a constant or the mean/median/mode (fillna), or model them; sometimes add a “was missing” flag. The choice depends on how much is missing and why.

Machine learning
Supervised vs unsupervised learning?

Supervised learning uses labelled examples to predict a target — classification (categories) or regression (numbers). Unsupervised learning finds structure without labels — clustering (K-Means) or dimensionality reduction (PCA).

Why do we split data into train and test sets?

To measure performance on data the model hasn't seen. A score on training data rewards memorisation; the test score estimates real-world performance. Cross-validation repeats the split several times for a more reliable estimate.

What are overfitting and underfitting?

Overfitting: great on training data, poor on test data — the model learned noise (fix: simpler model, regularisation, more data, limit tree depth). Underfitting: poor on both — the model is too simple (fix: more features, a more flexible model).

Precision vs recall?

Precision: of everything predicted positive, how much really is positive. Recall: of all real positives, how many were found. Spam filters favour precision (don't lose real mail); disease screening favours recall (don't miss a case). F1 balances both.

Decision tree vs random forest?

A single tree is easy to read but overfits easily. A random forest trains many trees on random samples of rows and features and lets them vote — more accurate and stable, less interpretable, with feature importances as a summary.

How does K-Means work, and how do you choose K?

Pick K centroids, assign each point to the nearest, move each centroid to the mean of its points, repeat until stable. Choose K with the elbow method (plot within-cluster sum of squares against K) or the silhouette score.

Why is Naive Bayes “naive”?

It assumes features (e.g. words) are independent given the class. That's rarely true, but the model is fast, needs little data and works surprisingly well for text classification.

Text & scraping
Stemming vs lemmatization?

Stemming chops suffixes by rules and may produce non-words (changes → chang). Lemmatization uses a dictionary and part of speech to return the real base form (changed → change, better → good). Lemmatization is more accurate, stemming faster.

What are stop words, and when should you keep them?

Very common words (“the”, “is”) removed to focus on meaningful words. Keep them when they matter — negations like “not” in sentiment analysis, or for models that read full sentences.

How do you turn text into numbers for a model?

Tokenize, build a vocabulary, then encode: word IDs, bag-of-words counts (CountVectorizer), TF-IDF weights, or dense embeddings (Word2Vec, transformer models).

requests + BeautifulSoup vs Selenium — when do you need Selenium?

requests fetches the HTML the server sends; BeautifulSoup parses it — fast and light. If content is created by JavaScript after the page loads (infinite scroll, clicks, logins), requests sees an empty shell; Selenium drives a real browser so you get what users see.
